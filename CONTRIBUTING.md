# Contribuer à SportAnalytics Pro

Merci de votre intérêt ! Voici comment contribuer au projet.

## 🐛 Signaler un bug

Ouvrez une issue sur GitHub en précisant :

- Version de Python
- Système d'exploitation (Termux, Linux, macOS, Windows)
- Commande exécutée
- Message d'erreur complet
- Étapes pour reproduire

## 💡 Proposer une fonctionnalité

Ouvrez une issue pour discuter de l'idée avant de coder.

## 🔀 Pull Request

1. Fork le projet
2. Créez une branche descriptive
3. Respectez le style existant
4. Testez localement
5. Ouvrez une Pull Request
