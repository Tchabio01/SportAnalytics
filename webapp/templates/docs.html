🔌 API SportAnalytics

Accès programmatique au moteur d'analyse

Endpoints

GET /api/health

Vérifie que le service répond.

{"status": "ok", "service": "sportanalytics"}

GET /api/stats

Statistiques globales du modèle.

{"total": 42, "accuracy": 55.3, ...}

GET /api/predictions?n=10

Dernières prédictions (max 100).

GET /api/predict?home=Arsenal&away=Leeds

Analyse statistique d'un match.

{
  "probabilities": {"home_win": 55.1, ...},
  "expected_goals": {"home": 1.5, "away": 0.75},
  "confidence": 65
}

GET /api/h2h?home=Arsenal&away=Chelsea

Confrontations directes.
